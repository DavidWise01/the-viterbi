THE VITERBI ALGORITHM — THE TRANSCRIBER: you can only see the symptoms, never the cause — but from a stream of clues you can name the single most likely hidden story behind them. Given ‘normal, cold, dizzy’ the most probable run of health states is Healthy, Healthy, Fever. This is how a phone turns sound into words. ⚑ LIVE full-house instrument: the HMM trellis with the brightest path lit through the hidden states, observations feeding in; the trellis in 3D; tesseract 4D + shadow + toddler. ◆ LIT: fill a trellis where each cell’s best probability = max over previous states of (best × transition × emission), remembering the winner; traceback gives the most-likely hidden path; a fail-loud self-check throws unless the classic example decodes to Healthy → Healthy → Fever. ▲ AMBER: a tiny 2-state/3-symbol model with fixed probabilities (real decoders have thousands of learned states + beam search); the trellis recursion is exact.
